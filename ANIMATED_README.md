## 🏗️ Architecture

Browser → Frontend (Nginx - 80) → Backend (Node.js - 3100) → MongoDB

---

## 🛠️ Tech Stack

Frontend:
- React  
- Tailwind CSS  
- Axios  

Backend:
- Node.js  
- Express  
- Mongoose  

DevOps:
- Docker  
- GitHub Actions  
- SonarCloud  
- AWS EC2  

---

## 🚀 Getting Started

git clone https://github.com/Jayakrishnasai/SSP_MERN_Project.git  
cd SSP_MERN_Project  

---

## 🐳 Run with Docker

docker compose up -d --build  

Access:  
Frontend → http://localhost  
Backend → http://localhost:3100/courses  

---

## 📡 API

GET /courses  
POST /courses  
PUT /courses/:id  
DELETE /courses/:id  

---

## ⚙️ CI/CD

🧪 Test → 📊 Sonar → 🐳 Build → 🚀 Deploy  

---

## 🔒 Security

- MongoDB not exposed  
- Secrets via GitHub  
- SHA-based Docker tagging
